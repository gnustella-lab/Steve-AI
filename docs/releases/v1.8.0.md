# Steve AI 1.8.0 — Local-first autonomy

Steve can now plan and execute supported resource gathering, crafting, and smelting goals locally, using the language model only when local planning cannot handle the request.

## Added

- Local planning for simple `craft` / `make`, `smelt`, and `gather` / `collect` / `mine` goals.
- Support for registered item IDs, mod namespaces, and simple English item names.
- Inventory-aware planning: request a desired inventory total and Steve produces only the missing quantity. Already satisfied goals complete without consuming materials.
- Offline operation for supported goals with `[autonomy] maxLlmCallsPerGoal = 0`.
- The `localPlanning` configuration option, enabled by default.
- Seven dedicated Minecraft GameTests covering crafting, gathering, furnace smelting, existing inventory, pause/stop, denied permissions, and unsupported offline requests.

## Fixed

- Local execution no longer depends on initializing a language model or having an available LLM call budget.
- Prerequisite planning preserves requested quantities and accounts for ingredients already in inventory.
- Prerequisite nesting is limited to eight levels to prevent unbounded dependency chains.
- Local planning outcomes use valid execution state transitions.

## Behavior and compatibility

- Existing permissions, pause/stop controls, bounded recovery, and deterministic goal verification remain enforced.
- Compound or unknown requests still use LLM fallback. With a zero-call budget, unsupported requests stop with an explanation.
- This release provides bounded local task planning; it does not add unrestricted offline language understanding or new proactive behavior.
- **Minecraft:** 1.20.1
- **Loader:** Forge (built against 47.2.0)
- **Java:** 17 or newer

## Installation

Download `steve-ai-mod-1.8.0.jar` from the release assets and place it in your Forge installation's `mods` directory. Replace the previous Steve AI JAR instead of keeping both versions. The installable JAR includes its required runtime libraries; do not use a `-slim.jar` build.

The accompanying `.sha256` file can be used to verify the download.

## Offline examples

```text
craft 8 oak_planks
smelt 16 iron_ingots
gather 4 oak_log
```

Quantities are inventory targets, not additional amounts. Recipe output batches may exceed the missing count.
